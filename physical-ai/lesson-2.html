Logic gates: how switches make decisions

You know that a computer is made of on/off switches and that 0s and 1s are just high and low voltages. But how do switches decide anything? The answer is logic gates: switches wired together in simple patterns. Click the switches below and watch.

Start with plain switches

Before chips existed, people built logic out of ordinary switches and relays in control panels. Two simple wiring patterns already make two decisions:

The AND gate

The lamp lights only when A and B are both on. Press Play to step through every combination, or click the switches yourself.

The OR gate

The lamp lights when A or B is on, or both.

The NOT gate

NOT flips its input: on becomes off, off becomes on. The small circle on the drawing means “flip”.

Truth tables

The little table under each gate is called a truth table. It lists every possible input and the output you get. Engineers use truth tables to describe what a circuit must do before anyone builds it, and support people use them to check whether a circuit is doing what it should.

Gates at work: a real machine rule

Here's a rule you'd find on almost every DiGiKits machine or control panel:

The motor may run if Start is pressed AND the guard is closed AND NOT the emergency stop.

That one sentence is three gates. Try to make the motor spin, then hit the E-stop.

Safety note for real machines: in a real control panel, the emergency stop also cuts power through its own hard-wired safety circuit, not only through software or a logic chip. Logic decides; the safety circuit makes sure. You'll learn more about this in Phase 2, Day 14.

From gates to computers

AND, OR and NOT are enough to build anything a computer does. A few gates wired together can add two bits. A few more can remember a bit. Millions of them make a processor. It's the same idea as the layers in Lesson 1: simple pieces, stacked up, with each layer hiding the one below so people can think bigger.

Hands-on

1. Predict, then click

For each gate above, cover the truth table, say out loud what the lamp will do, then click to check. Do the motor rule the same way: which one switch always stops the motor?

2. Design a hallway light

Write the rule and the truth table for: “The hallway light turns on if motion is detected OR the wall switch is on, but only when it's dark.” Which gates did you use? Post your answer on the board below.

3. Gates in Python

Python has the same three gates built in. On the Pi, type python3 and try:

>>> True and False
False
>>> True or False
True
>>> not True
False
>>> start, guard, estop = True, True, False
>>> start and guard and not estop
True
