Python and GPIO

Make the Pi control real hardware: an LED, a button, and an LED strip.

Why it matters

DiGiKits products control lights and motors. Support means telling a software fault from a wiring fault.

Blink an LED

Wire GPIO17 → 330 Ω resistor → LED long leg; LED short leg → GND. Power off while wiring.

from gpiozero import LED, Button
from signal import pause

led = LED(17)
button = Button(27)        # button between GPIO27 and GND

button.when_pressed = led.on
button.when_released = led.off
pause()

Save as ~/practice/blink.py and run python3 ~/practice/blink.py. Ctrl+C to stop.

LED strip (WS2812)

  • Power the strip from its own 5 V supply, not the Pi. Connect the grounds together.
  • The Pi 5 needs a Pi 5–compatible LED strip library; the older rpi_ws281x library does not support it. Choose the library with your coach.
  • Install extra Python packages in a virtual environment: python3 -m venv ~/venv then ~/venv/bin/pip install ...

Done when

  • The button turns the LED on and off
  • The strip runs a colour pattern from your own script

Support drill

The LED won't light. Is it the code, the pin number, the LED direction, or a loose wire? Find it.
