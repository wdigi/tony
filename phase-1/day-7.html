Python and GPIO

Make the Pi control real hardware: an LED, a button, and an LED strip.

📝Update progress on the message board below ↓

Why it matters

DiGiKits products control lights and motors. Support means telling a software fault from a wiring fault.

Blink an LED

Wire GPIO17 → 330 Ω resistor → LED long leg; LED short leg → GND. Power off while wiring.

from gpiozero import LED, Button
from signal import pause

led = LED(17)
button = Button(27)        # button between GPIO27 and GND

button.when_pressed = led.on
button.when_released = led.off
pause()

Save as ~/practice/blink.py and run python3 ~/practice/blink.py. Ctrl+C to stop.

Just enough Python

You don't need to be a programmer to support DiGiKits devices, but you must read a short script and spot what it does. Five ideas cover most of it:

count = 0                     # a variable: a named box holding a value
if button.is_pressed:         # a decision; the indented lines run only if true
    count = count + 1
for i in range(3):            # a loop: do this 3 times
    led.blink(on_time=0.2, off_time=0.2, n=1, background=False)
def flash(times):             # a function: a named recipe you can reuse
    led.blink(n=times, background=False)
print("count is", count)      # show something in the terminal
Indentation is part of the code. Python uses the spaces at the start of a line to know what belongs inside an if, loop or function. Use 4 spaces, never mix with tabs.

How the button input works

Button(27) turns on the Pi's built-in pull-up: GPIO27 is held at 3.3 V (reads "not pressed") until the button joins it to GND (reads "pressed"). That's why the button goes between the pin and GND, with no resistor. Real buttons also "bounce": one press makes several quick contacts. bounce_time ignores the extras.

Done when

  • The button turns the LED on and off
  • You write two more scripts of your own (e.g. the LED blinks faster on each press)
  • You can read a traceback: what went wrong, and on which line
  • You made an LED fade with PWMLED
  • You can explain why the button needs no resistor (pull-up)

Support drill

The LED won't light. Is it the code, the pin number, the LED direction, or a loose wire? Find it.

More cases

Try each one before you open the answer.

“GPIOPinInUse: pin GPIO17 is already in use.”

Another program holds the pin, often your Day 9 service or an old script still running. Find it: ps aux | grep python. Stop the service (sudo systemctl stop blink) or end the old script.

“IndentationError: unexpected indent” on line 6.

Line 6 has extra spaces or a tab where Python didn't expect them. Make the indentation match the lines around it, 4 spaces per level.

Each button press counts 2 or 3 times.

Contact bounce. Use Button(27, bounce_time=0.05).

The script works with sudo but not without.

Permission on the GPIO device: the user isn't in the gpio group (Day 5). Fix the group; don't run it as root.
