Phase 1 · Day 3

The terminal

Work with files using only the keyboard.

📝Update progress on the message board below ↓

Why it matters

Remote support has no mouse. Everything happens in a terminal.

Practice

pwd                      # where am I?
ls -la                   # list everything, with details
mkdir -p ~/practice/logs # make folders
cd ~/practice
nano notes.txt           # write a few lines, Ctrl+O, Ctrl+X
cat notes.txt            # show the file
cp notes.txt logs/       # copy
mv logs/notes.txt logs/old.txt   # rename
rm logs/old.txt          # delete (no undo!)
history                  # what did I type?
man ls                   # the manual (q to quit)

Use the Tab key to finish names and the Up arrow to repeat commands.

Anatomy of a command

Paths: absolute and relative

You typeMeans
/home/tony/practiceAbsolute: from the top of the tree. Works from anywhere.
practice/logsRelative: from the folder you're in now.
~Your home folder
. and ..This folder, and the one above it (cd .. goes up)
.bashrcA name starting with a dot is hidden. ls -a shows it.
"my notes.txt"Quotes for names with spaces. Better: don't use spaces in names.

Reading files like a support person

less /var/log/syslog          # page through (Space, b, /word to search, q to quit)
head -20 notes.txt            # first 20 lines
tail -20 notes.txt            # last 20 lines
tail -f /var/log/syslog       # follow new lines live (Ctrl+C to stop)
grep -i error notes.txt       # only lines containing "error"
wc -l notes.txt               # count lines
du -sh ~/*                    # how big is each folder?

Pipes and redirects

SymbolDoesExample
|Send output to the next commandls | wc -l
>Save output to a file (replaces it!)ls > list.txt
>>Add output to the end of a filedate >> log.txt
*Any charactersls *.txt

Keys that save you

KeysDoes
Ctrl+CStop the running command
Ctrl+RSearch your command history: type part of an old command
Ctrl+LClear the screen
Ctrl+A / Ctrl+EJump to start / end of the line
qLeave less, man, htop
Copying commands from the internet or from an AI? Read every command before you press Enter, and ask what each part does. Never run anything with rm -rf, curl … | sh or sudo that you don't understand.

Done when

  • You finish a 20-step file task your coach writes, without the mouse
  • You can find any file with find ~ -name "notes*"
  • You can name the three parts of any command
  • You can explain absolute and relative paths, ~ and ..
  • You counted the error lines in a log with one pipe
  • You found the biggest folder in your home with du

Support drill

A config file has been moved somewhere in your home folder. Find it and put it back.

More cases

Try each one before you open the answer.

cat my notes.txt says “No such file or directory”.

The space splits it into two names: my and notes.txt. Use quotes: cat "my notes.txt", or press Tab to complete the name.

“htop: command not found”.

The program isn't installed (or it's spelled wrong). Install it with sudo apt install htop (Day 5).

“The Pi says the disk is full.”

df -h shows how full. Then du -sh /home/* /var/log and go into the biggest folder to find what's eating space. Often an old log or a forgotten download.

You're stuck inside nano and can't get out.

Ctrl+X leaves. It asks to save: Y or N. In less or man, press q.
