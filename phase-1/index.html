Phase 1: Raspberry Pi and Linux

11 days, 6 hours a day. By the end you can set up a Pi from a blank card, reach it from anywhere, run a program as a service, and find out why it stopped working.

Almost every DiGiKits product runs on a Raspberry Pi, so this is the core of support work.
