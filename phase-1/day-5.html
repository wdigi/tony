Phase 1 · Day 5

Users, permissions, packages

Understand who can do what on a Linux computer, and install software safely.

📝Update progress on the message board below ↓

Why it matters

"Permission denied" is one of the most common faults you will see.

Practice

whoami ; groups           # who am I, which groups?
ls -l                     # -rw-r--r-- = owner / group / everyone
chmod +x myscript.sh      # make a script runnable
sudo chown yourname file  # change the owner
sudo cat /etc/shadow      # sudo = run as admin; use it carefully

apt search htop           # find software
sudo apt install htop     # install
htop                      # try it (q to quit)
sudo apt remove htop      # remove

Done when

  • You can explain the 10 letters in -rwxr-xr--
  • You fix a "permission denied" on a script your coach gives you

Support drill

A program can't write its log file. Find the permission problem and fix it without using chmod 777.
