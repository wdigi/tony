Phase 1 · Day 8

LED strip

Drive a WS2812 LED strip, the same kind DiGiKits LED controllers use.

Why it matters

Most lighting faults are power or wiring, not code. Today you learn to tell them apart.

Setup

  • Power the strip from its own 5 V supply, not the Pi. Connect the grounds together.
  • The Pi 5 needs a Pi 5–compatible LED strip library; the older rpi_ws281x library does not support it. Choose the library with your coach.
  • Install extra Python packages in a virtual environment: python3 -m venv ~/venv then ~/venv/bin/pip install ...
  • Check the arrow on the strip: data flows one way. Solder wires to the input end if needed.

    • Done when

    • The strip runs three colour patterns you wrote
    • You can explain why the strip has its own power supply

    Support drill

    Half the strip shows wrong colours. Is it power, ground, the data line, or the code? Find it.
