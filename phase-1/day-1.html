Welcome: DiGiKits and GitHub

Before any hardware: what DiGiKits does, why your skills matter to it, and your own GitHub account.

1 · What DiGiKits does

DiGiKits Inc. has used the same name for 20 years. Its new website describes it as a platform where anyone can turn an idea into a real, working product, online, on real hardware. The motto is From thoughts to things.

  • Design: a free library of open-source modules (each reviewed by a named professional) and AI-assisted circuit board design.
  • Test: DiGiKits Lab. Customers' boards are tested on real test beds, run by scripts and watched by camera. An AI called DigitLab runs the lab.
  • Build: optional. Buy a module, keep it stored in the lab, or copy the open design into your own board.
  • Solutions for small businesses: 3D showrooms for retail stores, lighting previews for interior designers, sales centres for real estate, and LED lighting.
  • First product: the DiGiKits LED Controller, a network-controlled driver for WS2812 LED strips.

Read the full picture on the DiGiKits website mock-up when your coach shows it to you.

2 · Why you are learning these skills

As an assistant and technical support person, your job is to keep DiGiKits machines and software running, and to help customers when something goes wrong. Almost all of it runs on small Linux computers.

3 · What GitHub is, and why

  • Git is a program that saves every version of your files. Nothing is lost; you can always go back.
  • GitHub is a website that stores those files online, so a team can work on the same files from anywhere.
  • DiGiKits keeps all its code and documents on GitHub. To get access, your coach adds your account to the company's projects.
  • Your GitHub account is also your public work record: what you build there shows what you can do.

4 · Get a free GitHub account

  1. Go to github.com/signup.
  2. Enter your email, a strong password (4–5 random words, or one from a password manager) and a username. The username is public and awkward to change later, so keep it professional, e.g. based on your name.
  3. Solve the check, then type the code GitHub emails you.
  4. Choose the Free plan. You don't need anything paid.
  5. Turn on two-factor authentication: profile picture → Settings → Password and authentication → Enable two-factor authentication. Use an authenticator app on your phone. Save the recovery codes somewhere safe.
  6. Text your username to your coach. Only the username, never the password or codes.

Afternoon: do GitHub's own short "Hello World" exercise (search "GitHub Hello World docs") to try a repository, a branch and a change.

Done when

  • You can explain what DiGiKits does in three sentences
  • Your GitHub account works and two-factor authentication is on
  • Your coach has your GitHub username
