Phase 1 · Day 10

Git and backup

Track changes with Git and keep a full backup of your Pi.

Why it matters

All DiGiKits code lives on GitHub. A backup turns a dead card into a 30-minute fix.

Git basics

git config --global user.name "Your Name"
git config --global user.email "the email you used for GitHub on Day 1"
git clone https://github.com/OWNER/REPO.git
cd REPO
nano README.md                 # make a change
git status
git add README.md
git commit -m "Update readme"
git push

Pushing needs GitHub sign-in: an SSH key (like day 4) or a personal access token.

Back up the SD card

  1. Put the second SD card in the USB card reader and plug it into the Pi.
  2. Pi menu → Accessories → SD Card Copier. Copy from the internal card to the USB card.
  3. Label it with the date. To restore: swap it in and boot.

Done when

  • You push a commit to a practice repo
  • You restore a broken Pi from your backup in under 30 minutes
