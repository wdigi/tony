Support note template

Write one after every drill and every real fault. 3–5 lines is enough. These notes become the DiGiKits support knowledge base.

Date:
Device:        (e.g. Pi 5, hostname)
What I saw:    (the symptom, exact error text)
What I tried:  (in order)
What fixed it:
Next time:     (how to spot it faster)

AI chat sidebar in the Pi browser

Keep an AI chat open beside any page while you learn.

  1. Open Firefox (Pi menu → Internet → Firefox). Not there? In Terminal: sudo apt install firefox
  2. Menu (three lines, top right) → Settings → General → Browser Layout → tick Show sidebar.
  3. Click the sparkle icon in the sidebar.
  4. Pick Claude, the AI DiGiKits works with, click Continue, and sign in. (ChatGPT and Gemini are there too.)

Tip: select text on any page and ask the chat to explain it. Never paste passwords or customer details into a chat.
