Phase 2 · Day 9

Docker, part 2: Compose

Describe a whole app in one file and start it with one command.

Why it matters

Real systems are several containers (web page, database, a worker). Compose keeps them together and restarts them after a reboot.

Practice

Create ~/dash/compose.yaml:

services:
  web:
    image: nginx
    ports:
      - "8080:80"
    volumes:
      - ./site:/usr/share/nginx/html:ro
    restart: unless-stopped
  uptime:
    image: louislam/uptime-kuma:1
    ports:
      - "3001:3001"
    volumes:
      - ./uptime-data:/app/data
    restart: unless-stopped
cd ~/dash
docker compose up -d
docker compose ps
docker compose logs -f uptime
docker compose pull && docker compose up -d   # update

Open Uptime Kuma on port 3001 and add monitors for your Pis and your fake LED controller (port 5000).

Done when

  • Both containers come back after sudo reboot
  • Uptime Kuma shows red when you stop the fake controller

Support drill

A container keeps restarting. Read its logs and find why.
