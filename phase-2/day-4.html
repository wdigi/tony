Phase 2 · Day 4

The Big Screen, part 2: control

Turn the TV on and off from the Pi, and switch what it shows with a physical button.

📝Update progress on the message board below ↓

Why it matters

Clients want screens to switch on at opening time and off at night, and staff want one button, not a keyboard.

TV control over HDMI (CEC)

sudo apt install cec-utils
echo 'scan' | cec-client -s -d 1        # what is connected?
echo 'standby 0' | cec-client -s -d 1   # TV off
echo 'on 0' | cec-client -s -d 1        # TV on

Not every TV supports CEC, and it may need turning on in the TV's menu (brands call it Anynet+, SimpLink, Bravia Sync and so on).

A mode button

Use the button and LED on your controller from Phase 1 Day 7: each press switches between two web pages, and the LED shows which mode is on. The controller reports BUTTON over the network; a Python script on the kiosk Pi switches the page and tells the controller which LED state to show.

Schedule

Use a timer from Day 2 to switch the TV on at 9:00 and off at 18:00.

CEC in more depth

Every device on the HDMI chain has a CEC address. The TV is always 0; the Pi is usually a "playback device", 4.

cec-client -l                          # list CEC adapters (a Pi 5 has one per HDMI port)
echo 'pow 0' | cec-client -s -d 1      # ask the TV: on or standby? (great for remote checks)
echo 'as' | cec-client -s -d 1         # "active source": switch the TV's input to the Pi

If the TV turns on but shows another input, send as after on 0.

The mode button, complete

#!/usr/bin/env python3
# ~/bin/modes.py  - controller button switches the page; controller LED shows which one
import os, subprocess, sys
sys.path.insert(0, "/home/tony/practice")          # where controller.py lives
from controller import connect, send

PAGES = ["https://wdigi.github.io/tony/", "https://wdigi.github.io/tony/lessons.html"]
env = dict(os.environ, WAYLAND_DISPLAY="wayland-0", XDG_RUNTIME_DIR=f"/run/user/{os.getuid()}")
mode = 0

def show(i):
    subprocess.run(["pkill", "-f", "chromium"])
    subprocess.Popen(["chromium", "--kiosk", "--incognito", PAGES[i]], env=env)
    send(f, f"LED {i}")                               # LED on = page 2

f = connect()
show(mode)
while True:
    line = f.readline().strip()
    if not line:
        break                                         # lost the controller: let systemd restart us
    if line == "BUTTON":
        mode = 1 - mode
        show(mode)

The env line matters: a script started from SSH or a service doesn't know about the screen unless you tell it which display to use. If the network drops, the script ends; run it as a service with Restart=always (Phase 1 Day 9) and it reconnects by itself.

Opening hours with timers

# /etc/systemd/system/tv-on.service
[Service]
Type=oneshot
ExecStart=/bin/sh -c "echo 'on 0' | cec-client -s -d 1; sleep 5; echo 'as' | cec-client -s -d 1"

# /etc/systemd/system/tv-on.timer
[Timer]
OnCalendar=Mon..Sat 08:55
Persistent=true
[Install]
WantedBy=timers.target

Make a matching tv-off pair with standby 0 at 18:05.

When CEC isn't available

Some TVs ignore CEC. Commercial displays usually have a better way: a network or RS-232 control port with documented commands. Last resort: the TV's own on/off timer, or a smart plug for the screen (not for the Pi).

Done when

  • The TV turns on and off from a command
  • A button press switches the page and the LED shows the mode
  • You can ask the TV its power state with pow 0
  • Your mode script switches pages from a button, started without a keyboard
  • tv-on and tv-off timers are listed in systemctl list-timers

Support drill

"The screen won't turn on in the morning." List five possible causes and how you'd test each one remotely.

More cases

Try each one before you open the answer.

cec-client scan finds no TV.

Wrong adapter or HDMI port (cec-client -l), CEC switched off in the TV menu, or the cable/adapter doesn't carry CEC. Try the other HDMI port and a direct cable.

The TV turns on, but shows the cable box.

Send as (active source) a few seconds after on 0.

modes.py works from the Pi's own terminal, but from SSH the browser never appears.

The script doesn't know the display. Set WAYLAND_DISPLAY and XDG_RUNTIME_DIR as in the script above.

The TV switched off at 18:05 Saturday, but not Sunday morning on.

Check the OnCalendar days: Mon..Sat doesn't include Sunday. systemd-analyze calendar shows the next run.
