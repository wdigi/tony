Phase 2 · Day 8

Docker, part 1

Run software in containers: packaged apps that work the same on every machine.

Why it matters

DiGiKits software is shipped and updated as containers. "It worked on my machine" stops being a problem.

Practice

curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER     # then log out and back in
docker run hello-world
docker run -d --name web -p 8080:80 nginx
docker ps
docker logs web
docker stop web && docker rm web

Open http://trainpi:8080 from your laptop while the container runs.

Serve your own page: put an index.html in ~/site and run

docker run -d --name web -p 8080:80 -v ~/site:/usr/share/nginx/html:ro nginx

Learn the words

Image (the package), container (a running copy), port mapping (8080 outside → 80 inside), volume (a folder shared with the container).

Done when

  • Your own page is served from a container
  • You can explain image, container, port and volume

Support drill

"Port is already allocated." Find what's using it and fix it.
