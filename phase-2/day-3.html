Phase 2 · Day 3

The Big Screen, part 1: kiosk mode

Make a Pi start straight into a full-screen web page, with no desktop showing. That is how DiGiKits demo and dashboard screens work.

Why it matters

A showroom screen must come back on its own after a power cut, with no keyboard and nobody touching it.

Steps

  1. Turn off screen blanking: sudo raspi-config → Display Options → Screen Blanking → No.
  2. Find your desktop type: echo $XDG_SESSION_TYPE (current Raspberry Pi OS uses Wayland with the labwc desktop).
  3. Add the browser to the desktop's autostart file. On labwc it is ~/.config/labwc/autostart: 
    chromium --kiosk --noerrdialogs --disable-infobars https://wdigi.github.io/tony/ &
    If chromium is not found, try chromium-browser. Older setups use a different autostart file; look up your OS version's method.
  4. Reboot and check it comes up full screen.
  5. Hide the mouse pointer and set the screen to never sleep (search your OS version's way; write down what worked).

Done when

  • Pulling the power and plugging it back in brings the page back full screen
  • You wrote down every step in your own words (you need it on Day 15)

Support drill

The screen shows "This site can't be reached" after boot. The page works later. Why? (Hint: the network may not be ready yet.)
