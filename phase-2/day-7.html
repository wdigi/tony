Microcontrollers and MicroPython

Program a small microcontroller board, the kind inside DiGiKits LED controllers.

Why it matters

A Pi is a full computer. A microcontroller is a tiny one that runs one job, starts in a blink and almost never crashes. DiGiKits products use both.

Steps (Raspberry Pi Pico 2)

  1. Download the MicroPython file (.uf2) for your board from micropython.org.
  2. Hold the BOOTSEL button, plug in USB, release. A drive appears; copy the .uf2 file onto it.
  3. Install Thonny on your laptop or Pi; choose the MicroPython interpreter.
  4. Blink the onboard LED: 
    from machine import Pin
import time
led = Pin("LED", Pin.OUT)
while True:
    led.toggle()
    time.sleep(0.5)
  5. Drive your LED strip (data on GP0, strip on its own 5 V supply, grounds joined): 
    import neopixel, machine
np = neopixel.NeoPixel(machine.Pin(0), 30)
for i in range(30):
    np[i] = (0, 0, 40)
np.write()
  6. Save it as main.py on the board so it runs at power-on.

Done when

  • The strip runs a pattern from the Pico with no computer attached
  • You can explain the difference between a Pi and a microcontroller

Support drill

The board doesn't show up when plugged in. Is it the cable (some are charge-only), the mode, or the board?
