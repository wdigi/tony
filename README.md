# DiGiKits Support Training

Training materials for DiGiKits technical support, published with GitHub Pages.

- `index.html` — plan and roadmap
- `phase-1/` — Raspberry Pi and Linux, one page per week
- `kit.html` — starter kit
- `tools.html` — support note template, AI sidebar tip, command cheat sheet
- `coach.html` — coach view of every trainee's tick boxes (coaches only)
- `progress-server/` — the small server that saves tick boxes under each trainee's GitHub sign-in

The site is public on the internet even though this repo is private. Keep personal details (names, family, pay, contact info, passwords, IP addresses) out of every file here.
