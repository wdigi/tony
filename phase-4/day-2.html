Phase 4 · Day 2

FreeCAD: sketch and pad

Make your first real part: a plate with holes, from a sketch.

📝Update progress on the message board below ↓

Steps

  1. Part Design workbench → Create body → Create sketch on the XY plane.
  2. Draw a rectangle 100 × 60 mm and four circles 3.2 mm across, 5 mm in from each corner. Add dimensions so the sketch turns fully constrained (it changes colour).
  3. Close the sketch and Pad it 3 mm.
  4. Add a Fillet of 2 mm to the four corner edges.
  5. Export as STEP and as STL.

Constraints: pin the sketch down

Design intent: make changes easy

  • Centre on the origin with a Symmetric constraint. Make the plate 120 mm long and it grows equally both ways.
  • One hole size, four holes: dimension one circle, make the others Equal to it.
  • Name important dimensions. Double-click a constraint and give it a name (for example hole_d). Other features can use it in an expression, so one change updates everything.
  • Fillets and chamfers last. They depend on edges that earlier features create; added early, they're the first thing to break when you change something.

Exporting

Select the Body (not the sketch) in the tree, then File → Export. Choose STEP for exact CAD or STL for printing. STL asks how fine the mesh should be (Day 1).

Done when

  • A fully constrained plate with holes, exported in two formats
  • Your plate is centred with a Symmetric constraint
  • The four holes use Equal and one named diameter
  • Changing the plate length updates everything, fillets included

More cases

Try each one before you open the answer.

Pad fails: “Wire is not closed”.

There's a gap in the sketch outline, often two points that look joined but aren't. Add Coincident constraints at the corners, or use Sketch → Validate sketch to find open ends.

The sketch turns red: conflicting constraints.

Two constraints disagree (for example two lengths for the same line). Undo the last one, or delete one of the pair the solver lists.

After changing the plate size, the fillet broke.

The edges it used changed. Edit the fillet and pick the edges again, and keep fillets as the last features.
