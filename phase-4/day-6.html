Practice (Three.js)

Create index.html and open it through a simple local server (python3 -m http.server):

<script type="importmap">
{ "imports": { "three": "https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js" } }
</script>
<script type="module">
import * as THREE from "three";
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.set(2, 2, 3); camera.lookAt(0, 0, 0);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);
scene.add(new THREE.AmbientLight(0xffffff, 0.5));
const sun = new THREE.DirectionalLight(0xffffff, 1); sun.position.set(3, 5, 2); scene.add(sun);
const box = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), new THREE.MeshStandardMaterial({ color: 0x1f6feb }));
scene.add(box);
renderer.setAnimationLoop(() => { box.rotation.y += 0.01; renderer.render(scene, camera); });
</script>

Keep it sharp when the window changes

addEventListener("resize", () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
renderer.setPixelRatio(Math.min(devicePixelRatio, 2));   // sharp, but not too heavy

Lights and materials

Material settingDoes
colorThe base colour
roughness (0–1)0 = mirror-shiny, 1 = matt
metalness (0–1)How metal-like it looks
renderer.shadowMap.enabled = true;
sun.castShadow = true;
box.castShadow = true;
floor.receiveShadow = true;     // shadows cost speed: use them where they matter

What happens every frame

When the page stays blank

Open the browser's developer tools (F12, or right-click → Inspect) and look at the Console. Three.js errors and typos show up there in red, with the line number.

Done when

  • A lit, rotating box in your browser
  • You changed its colour, size and the camera position
  • Your scene stays sharp and undistorted when you resize the window
  • You tried all four light types and changed roughness and metalness
  • A shadow falls on a floor

More cases

Try each one before you open the answer.

The page is blank and the console says the module couldn't be loaded, or mentions CORS.

You opened the file directly (file://). Serve it: python3 -m http.server and open http://localhost:8000.

The box is completely black.

MeshStandardMaterial needs light. Add an ambient light and a directional light, or check the light is added to the scene.

After resizing the window, the box is stretched.

The camera's aspect wasn't updated. Add the resize handler above.

It runs smoothly on your laptop, jerky on the Pi.

Too much work per frame: fewer triangles, fewer shadows, lower pixel ratio. Always test on the Pi early.
