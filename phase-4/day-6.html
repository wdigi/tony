Phase 4 · Day 6

3D on the web, part 1

Show a 3D scene in a web browser, the way DiGiKits 3D showrooms and demos work.

Practice (Three.js)

Create index.html and open it through a simple local server (python3 -m http.server):

<script type="importmap">
{ "imports": { "three": "https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js" } }
</script>
<script type="module">
import * as THREE from "three";
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.set(2, 2, 3); camera.lookAt(0, 0, 0);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);
scene.add(new THREE.AmbientLight(0xffffff, 0.5));
const sun = new THREE.DirectionalLight(0xffffff, 1); sun.position.set(3, 5, 2); scene.add(sun);
const box = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), new THREE.MeshStandardMaterial({ color: 0x1f6feb }));
scene.add(box);
renderer.setAnimationLoop(() => { box.rotation.y += 0.01; renderer.render(scene, camera); });
</script>

Done when

  • A lit, rotating box in your browser
  • You changed its colour, size and the camera position
