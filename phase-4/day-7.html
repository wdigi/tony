3D on the web, part 2

Load a real model, let the viewer orbit around it, and show it on the Big Screen.

📝Update progress on the message board below ↓

Practice

  1. Export your enclosure as a mesh and convert it to GLB (FreeCAD or Blender can do this).
  2. Load it with Three.js GLTFLoader, and add OrbitControls so the mouse or a touch screen can turn it.
  3. Add a button that switches a light on and off in the scene.
  4. Publish the page (GitHub Pages works) and show it on your Phase 2 Big Screen in kiosk mode.

Loading and framing a model

import { GLTFLoader } from "three/addons/loaders/GLTFLoader.js";
import { OrbitControls } from "three/addons/controls/OrbitControls.js";
// importmap also needs: "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.170.0/examples/jsm/"

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;

new GLTFLoader().load("models/pi-box.glb", (gltf) => {
  const model = gltf.scene;
  // centre it and fit the camera to its size
  const box = new THREE.Box3().setFromObject(model);
  const size = box.getSize(new THREE.Vector3()).length();
  model.position.sub(box.getCenter(new THREE.Vector3()));
  camera.position.set(size, size * 0.7, size);
  camera.near = size / 100; camera.far = size * 10; camera.updateProjectionMatrix();
  controls.target.set(0, 0, 0);
  scene.add(model);
});
// in the loop: controls.update();

Centring and fitting the camera means any model shows up nicely, whether it's 0.1 m or 10 m big.

More cases

Try each one before you open the answer.

Works on your laptop, but the published page shows nothing; the console says 404 for the model.

File names on GitHub Pages and Linux are case-sensitive: Pi-Box.glb ≠ pi-box.glb. Match the name exactly.

The model loads but you can't see it.

It's huge or tiny, or the camera is inside it. Use the centre-and-fit code above.

The model is white and grey, no colours.

The colours didn't make it into the GLB. Set colours or materials before export, or apply materials in Three.js after loading.
