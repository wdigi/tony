How to work

  • Small steps: something visible working by the end of each day.
  • Commit to GitHub at least once a day with a clear message.
  • Use AI to explain and draft code, and check everything it gives you (Day 2 rules).
  • Post progress on the message board: one screenshot and one line.

Build a thin slice, not a layer

Your task list: GitHub issues

Turn the Must pile into GitHub issues, one per small task (half a day or less). Close each with a commit that says Fixes #3. At any moment, the issues show what's done and what's left (Phase 2 Day 10).
